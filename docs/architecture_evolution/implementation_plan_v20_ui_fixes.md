# マップUI配置及びラベル重なりの修正計画

ご指摘いただいた「フィルタパネルの配置ミス」と「3次波及ノードの重なり」を修正し、地図内での視認性を最適化します。

## ユーザーレビューが必要な項目 (User Review Required)

> [!IMPORTANT]
> **配置の厳格化**
> *   フィルタパネルを Leaflet 純正の `L.Control` 拡張として実装し直し、地図のズームや移動に関わらず常に「地図エリア内（左上）」に固定されるようにします。
> *   これにより、サイドバーや他のUI要素との干渉を完全に防ぎます。

---

## 提案される変更 (Proposed Changes)

### 1. フィルタパネルの地図内固定 (`render.ts`)
*   **継承**: `L.Control.extend` を使用してフィルタパネルを定義。
*   **配置**: `position: 'topleft'` を指定し、Leaflet の標準コントロールレイヤーに組み込みます。
*   **CSS**: `.map-filter-panel` が地図の外にはみ出さないよう、`position: relative` (Control内) に調整。

### 2. ノード重なりの解消ロジック (`render.ts`)
*   **動的オフセット**: 
    *   `renderImpactChain` 内で、ノードの描画位置に `level` と `index` に基づく微小なオフセットを加えます。
    *   **垂直方向の回避**: 親ノードと同じ緯度に重なりそうな場合、3次ノードを距離の数パーセント分上（または下）に「逃がす」ことで、アークとラベルの重なりを防ぎます。
*   **ラベル・ジッター**: 同一地点に複数のステークホルダーが集中する場合、`iconAnchor` を数ピクセルずつずらして視認性を確保します。

### 3. デモデータの調整 (`render.ts`)
*   NVIDIA, TSMC, AWS の座標を僅かに調整、またはオフセットロジックが機能することを確認するための配置変更。
