# マップ・インテリジェンス・フィルタ及び高精度ラベルの実装計画

この計画では、マップ上の複雑な波及効果を整理するための「分野別フィルタ」を導入し、ノードのデザインをモックアップ（GitHub参考画像）と同等の情報密度（マルチライン、変動矢印、分野タグ）に引き上げます。

## User Review Required

> [!IMPORTANT]
> **フィルタリングによる視認性の確保**
> *   マップ左上に「Geopolitical」「Supply Chain」「Market」などのチェックボックスを配置し、表示するアークを動的に切り替えられるようにします。
> *   これにより、「本番環境で曲線だらけで見にくい」という課題を「レイヤー選択」によって解決します。

---

## 提案される変更 (Proposed Changes)

### 1. マップ・フィールドフィルタの実装 (`render.ts`)
*   **UI追加**: Leaflet の `leaflet-top leaflet-left` エリアに、セミ透明なガラスモーフィズム・パネルを設置。
*   **状態管理**: `activeFilters` (Set) を定義し、チェックボックスの変更に応じて `renderMap` を再実行（またはレイヤーのみ更新）。
*   **分野カテゴリ**: `[GEOPOLITICAL]`, `[SUPPLY CHAIN]`, `[GLOBAL MARKETS]` 等の定義を `topics.ts` または `render.ts` に追加。

### 2. 高精度ノードラベルへのアップグレード (`render.ts`)
*   **マルチライン表示**: 
    *   1行目: `[TOPIC] Entity Name` (例: `[SUPPLY CHAIN] TSMC`)
    *   2行目: `Alpha Prediction | Trend` (例: `-1.5% ↓`)
*   **視覚的インジケータ**: 変動の「矢印」と、強さ（Intensity）を示すドット/バーをラベル内に追加。
*   **スタイル**: モックアップに基づき、背景をより深く、境界線を強調したガラスモーフィズム・スタイルに変更。

### 3. CSS 拡張 (`style.css`)
*   `.map-filter-panel`: 左上のフローティングパネル用スタイル。
*   `.market-pulse-node--refined`: 新しい高度なラベル用スタイル。
